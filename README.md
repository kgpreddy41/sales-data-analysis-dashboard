# Sales Data Analysis Dashboard

## Project Overview

This project analyzes sales data using Python, Pandas, and Power BI to identify sales trends, regional performance, product performance, and profitability.

The project includes data generation, data cleaning, exploratory analysis, and an interactive Power BI dashboard.

## Business Objectives

- Analyze overall sales and profit performance
- Identify the best-performing product categories
- Compare sales across different regions
- Analyze monthly sales trends
- Identify the top 10 products by sales
- Provide interactive business insights using Power BI

## Technologies Used

- Python
- Pandas
- Matplotlib
- Power BI
- Git
- GitHub

## Project Workflow

1. Generated sales data using Python
2. Cleaned and analyzed the dataset using Pandas
3. Performed sales and profit analysis
4. Created visualizations using Python
5. Built an interactive Power BI dashboard
6. Added KPI cards, charts, and interactive filters

## Dashboard Features

The Power BI dashboard includes:

- Total Sales
- Total Profit
- Total Quantity
- Total Orders
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Top 10 Products by Sales
- Category slicer
- Region slicer
